هوبا بيتزا — ربط Supabase ولوحة تحكم وتتبع الطلبات
===================================================

الملفات
-------
1) index.html
   صفحة الموقع الأصلية مع إضافات الطلبات والتتبع وربط المنتجات والإعدادات بقاعدة البيانات.
2) admin.html
   لوحة إدارة منفصلة: تسجيل دخول، إحصائيات، إدارة الطلبات وتغيير الحالة، إدارة المنيو، إعدادات المتجر.
3) supabase_setup.sql
   إنشاء الجداول والفهارس وسياسات RLS ودوال تسجيل الطلب والتتبع وسجل الحالات والمنتجات الأولية.
4) index-original.html
   نسخة احتياطية كما وصلت من الملف المرفق قبل التعديل.

خطوات التشغيل بالترتيب
----------------------
1) افتح Supabase Dashboard للمشروع:
   https://supabase.com/dashboard/project/ljitbsjplgiwvcinxijj

2) افتح SQL Editor، أنشئ Query جديد، والصق محتوى supabase_setup.sql كاملاً ثم Run.
   الملف ينشئ المنتجات الثلاثة الموجودة في المنيو الحالي ورسوم توصيل افتراضية 25 جنيه.
   تقدر تغير رسوم التوصيل لاحقاً من لوحة التحكم؛ عدّلها حسب رسوم مطعمك الفعلية.

3) أنشئ حساب المدير من Supabase Dashboard > Authentication > Users > Add user.
   استخدم بريدك وكلمة مرور قوية. لا يوجد تسجيل مدير مفتوح من صفحة الموقع.

4) بعد إنشاء المستخدم، ارجع إلى SQL Editor وشغّل هذا الاستعلام بعد استبدال البريد:

   insert into public.admin_users (user_id, email)
   select id, email
   from auth.users
   where lower(email) = lower('YOUR-ADMIN-EMAIL@example.com')
   on conflict (user_id) do update set email = excluded.email;

5) ارفع index.html و admin.html إلى نفس مجلد الاستضافة/الموقع. افتح index.html للواجهة، وadmin.html للوحة الإدارة.
   سجّل الدخول في admin.html بالبريد وكلمة المرور التي أنشأتهما في الخطوة 3.

طريقة الطلب والتتبع
-------------------
- العميل يضيف المنتجات إلى السلة، ثم يكتب الاسم والموبايل وعنوان التوصيل ويؤكد الطلب.
- النظام يولّد كوداً مثل HP-A1B2C3D4. يجب الاحتفاظ بالكود ورقم الهاتف لتتبع الطلب.
- من زر "تتبع طلبك" في رأس الموقع، يدخل العميل كود الطلب ورقم الهاتف.
- الحالات: الطلب اتأكد، الطلب بيتجهز، خرج للتوصيل، تم التسليم، ملغي.
- تغيير الحالة من لوحة الإدارة يُسجل تلقائياً في سجل الحالات الذي يظهر في صفحة التتبع.
- العميل لا يستطيع قراءة قائمة الطلبات أو عناوين العملاء؛ دالة التتبع ترجع الطلب المطابق للكود ورقم الهاتف فقط.

أمان مهم
--------
- المفتاح sb_publishable_... مخصص للاستخدام في الواجهة، لذلك وجوده في ملفات HTML طبيعي.
- لا تضف أبداً service_role أو secret key إلى HTML أو JavaScript في المتصفح.
- الأمان الفعلي يعتمد على تشغيل supabase_setup.sql كما هو، بما فيه RLS والسياسات والدوال المقيّدة.
- قبل الاستخدام الحقيقي، جرّب إنشاء طلب تجريبي وتغيير حالته من حساب المدير ثم تتبعه من نافذة أخرى.
- رسوم التوصيل الافتراضية في الملف 25 جنيه كمثال قابل للتعديل، وليست معلومة مؤكدة عن مطعمك.

ملاحظات الحفاظ على النسخة الأصلية
---------------------------------
- ملف index-original.html نسخة كاملة غير معدلة من المصدر المرفق.
- ملف index.html يحتفظ بأقسام وتصميم ومحتوى الموقع الأصلي ويضيف حوله واجهات الطلب والتتبع.
- المنتجات الأولية المزروعة في قاعدة البيانات تطابق أسماء/أوصاف/أسعار المنتجات الثلاثة الظاهرة في الكود الأصلي.
